# Acknowledgements and third-party notices

## InMoov
The mechanical base design of ANANT builds on the **InMoov** open-source
3D-printed humanoid, created by **Gael Langevin** (https://inmoov.fr).
InMoov is released under a Creative Commons Attribution-NonCommercial
(CC BY-NC) license. Any printed parts or CAD derived from InMoov remain
subject to that license; please check inmoov.fr for the current terms before
any commercial use. The MIT license of this repository applies to the
software only.

ANANT's extensions beyond the InMoov base (full-scale integration, silicone
resistive touch skin, silicone expressive face, dual-compute control stack,
medical-simulation software, projector anatomy overlay, XR teleoperation)
are original work of this project.

## Software
Built on open-source libraries including OpenCV, dlib/face_recognition, Vosk,
eSpeak NG, Adafruit CircuitPython drivers, pyserial, websockets and PyYAML.
